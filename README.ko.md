## 사용 방법

### 내 화면에 맞는 배경화면 찾기
1. [mijuru.com/wallpapers](https://mijuru.com/wallpapers)를 엽니다.
2. **필터**를 사용합니다: **기기 유형**(휴대폰 또는 데스크톱), 해상도, 색상, 스타일.
3. 또는 [해상도](https://mijuru.com/wallpapers/resolutions)에서 정확한 화면 크기를 고르거나, [기기 브랜드](https://mijuru.com/wallpapers/device-brands)에서 휴대폰 브랜드를 고릅니다.
4. 배경화면을 열면 다운로드하기 전에 기기 프레임에서 미리 볼 수 있습니다.

### 알맞은 해상도로 다운로드하기
배경화면 페이지에서 제공되는 크기 중 하나를 고르세요. **4K**, **2K**, **FHD** 같은 배지로 화질을 한눈에 알 수 있습니다.

- **데스크톱 / 노트북:** 모니터 해상도를 고르세요(예: 1920×1080, 2560×1440, 3840×2160). 울트라와이드 모니터라면 21:9나 32:9가 있을 경우 그것을 고르세요.
- **휴대폰:** 세로 버전을 고르세요. 다른 방향 버전도 있다면 페이지에 링크가 있습니다.
- 정확한 크기가 없다면 화면비가 같은 한 단계 큰 크기를 고르세요. 기기가 화질 손실 없이 축소해 줍니다.

### 소셜 네트워크용 아바타 받기
1. [mijuru.com/avatars](https://mijuru.com/avatars)를 열고 카테고리나 네트워크(Instagram, Discord, TikTok, Steam, WhatsApp, Facebook)를 고릅니다.
2. 아바타 페이지에서 원형 크롭 미리보기를 확인하세요. 프로필에서 이렇게 보입니다.
3. 다운로드한 뒤 해당 네트워크의 프로필 설정에서 업로드합니다.

## 이용 및 라이선스

- mijuru.com의 배경화면과 아바타는 **개인적인 용도로 무료**입니다: 휴대폰, 컴퓨터, 태블릿, TV, 소셜 프로필에서 사용하세요.
- **금지 사항:** 이미지를 재판매하거나 상업적 목적으로 사용하는 것.
- Mijuru의 이름과 로고는 Mijuru에 귀속됩니다.

## 저작권 및 삭제 요청

mijuru.com에 있는 이미지의 권리자로서 이미지 삭제나 출처 표기를 원하신다면:

1. 이미지 페이지를 열고 **이미지 신고** 양식을 사용하거나,
2. 페이지 URL과 소유권 증빙을 첨부해 **m@mijuru.dev**로 이메일을 보내 주세요.

저작권 요청은 GitHub 이슈로 올리지 마세요. 이슈는 공개됩니다.

## 자주 묻는 질문

**Mijuru는 정말 무료인가요?**
네. 둘러보기와 다운로드 모두 무료이며 계정도 필요 없습니다.

**회원가입이 필요한가요?**
아니요. 사이트의 모든 기능을 계정 없이 이용할 수 있습니다.

**어떤 해상도를 골라야 하나요?**
화면의 기본 해상도를 고르세요. 목록에 없다면 화면비가 같은 한 단계 큰 크기를 고르세요. [알맞은 해상도로 다운로드하기](#알맞은-해상도로-다운로드하기)를 참고하세요.

**휴대폰용 배경화면도 있나요?**
네. 기기 유형으로 필터링하거나, [기기 브랜드](https://mijuru.com/wallpapers/device-brands)를 열거나, [Android 앱](#앱)을 이용하세요.

**배경화면을 제 YouTube 채널이나 광고에 쓰거나 인쇄물로 판매해도 되나요?**
아니요. 이미지는 개인적인 용도로만 사용할 수 있습니다.

**새 배경화면은 얼마나 자주 추가되나요?**
매일 추가됩니다.

**사이트 언어는 어떻게 바꾸나요?**
사이트의 **언어** 메뉴를 사용하거나, `mijuru.com/uk/` 같은 접두사가 붙은 주소로 접속하세요.

**다크 테마와 라이트 테마는 어떻게 전환하나요?**
사이트 헤더의 **테마** 메뉴를 사용하세요.

**원하는 카테고리나 해상도를 찾을 수 없어요.**
[요청해 주세요](https://github.com/orgs/mijuru-dev/discussions/categories/wallpaper-requests). 모든 요청을 읽습니다.

**계정, 즐겨찾기, 컬렉션 기능이 생기나요?**
계획 중입니다. 소식을 받으려면 이 저장소를 팔로우하세요.
